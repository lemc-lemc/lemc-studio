# Empezar con LEMC Studio 8.3.7

Abre **LEMC Studio.exe** en Windows x64. Mantén las carpetas del programa junto al ejecutable. La carpeta **docs** incluye la guía de uso, automatización y compilación. Las skills de Claude Code se encuentran en **.claude/skills**.

Para la primera exportación abre **Ejemplo ASCII desde video.json**. El clip de muestra está al lado del JSON. En consola puedes usar **Exportar con LEMC Studio.cmd**. Consulta **docs/AUTOMATIZACION.md** para instrucciones y ejemplos.

El software y el modelo incluidos están preparados para funcionar en local. Los avisos de dependencias se guardan en **Licencias**, **modelos** y los metadatos del entorno.
